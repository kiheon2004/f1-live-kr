# 검증 자료

README의 검증 수치가 무엇을, 어떤 조건에서 잰 것인지 정리한 문서입니다. 1–5는 2026-11-01, 6은 2026-11-11(v0.55) 작업 중 기록한 값입니다. 따로 적은 자동 테스트를 빼면, 이 문서를 쓰면서 다시 측정하지는 않았습니다.

## 측정 도구

모두 앱 안의 개발용 함수이며, 실제 화면과 같은 그리기 경로(`map3d.js`의 `updateCars`)를 거친 **최종 위치와 자세**를 잽니다.

| 도구 | 위치 | 재는 것 |
|---|---|---|
| `Map3D.poseScan(t0, t1, { fps })` | `src/renderer/map3d.js` | 보이는 모든 차의 최종 자세를 정해진 fps로 기록하고 이상 종류별로 셉니다. **jump**: 한 프레임 이동이 (속도 × 1.25 + 8 m/s) × 프레임 간격보다 큼. 그 밖에 yaw(방향 급변), lift(높이 급변), height(노면과 0.6 m 넘게 차이) |
| `Map3D.recordLive(secs)` | `src/renderer/map3d.js` | 실제 재생 중 몇 초 동안의 카메라·차 상태. v0.54부터 `sinkCm`(그린 차가 도로 아래로 내려간 깊이) 포함 |
| `Map3D.pitPathScan`, `Map3D.game.pitTrace` | `src/renderer/map3d.js`, `src/renderer/pitcheck.js` | 피트 레인에서 그린 차의 좌우 이동, 방향 변화, 정비 전후 작업 구역 주행 거리 |
| `Map3D.overlapScan` | `src/renderer/map3d.js` | 차량 모양 상자(5.6 × 2.0 m)끼리 겹친 차량 쌍-프레임 |

이 함수들을 여러 경기에 돌린 실행 스크립트, 원시 로그, 작업 보고서는 크기가 크고 개인 PC 경로가 들어 있어 저장소에 넣지 않았습니다. 아래 "근거"에는 그 기록의 이름만 적었습니다.

## 재현 가능한 대표 검증: 오프라인 데모 (`npm run verify:demo`)

위의 수치는 개발 중 기록이라 평가자가 그대로 다시 낼 수 없습니다(실제 기록 서버 접근과 저장소 밖 스크립트가 필요). 그래서 새 설치에서도 실행할 수 있는 검사 하나를 따로 두었습니다.

- **목적:** 오프라인 데모의 합성 세션이 실제 다시보기와 같은 처리 경로(`archive.js`의 해석 함수 → `replay.js`의 `Replay`, 위치 보간, 타이밍 상태, 스틴트)를 거쳐 정상적으로 재생되는지 확인합니다.
- **입력:** `src/main/demo.js`가 고정 규칙과 고정 시드로 만드는 가상 서킷(2.38 km), 차량 6대, 5바퀴, 피트 정차 1회. 실제 경기 기록, 사용자 캐시, 계정 정보는 쓰지 않습니다.
- **실행 조건:** `npm install` 뒤 `npm run verify:demo`. 인터넷, 로그인, Electron 창이 필요 없습니다. `npm test`에도 같은 검사가 들어 있습니다(`test/demo.test.js`).
- **통과 기준:** 아래 9개 검사가 모두 PASS이면 종료 코드 0, 하나라도 FAIL이면 1입니다.

2026-11-01, macOS(Apple Silicon), Node.js 24.21.0에서 실제로 실행한 출력:

```
PASS  same session every run (fixed seed) – digest e4c4d7d44d7893b2
PASS  6 cars, lights out and a finalised end found – 6 cars, lights out 65000 ms, end 287750 ms
PASS  every place finite (no NaN / Infinity) – 16968 car-samples, 0 not finite
PASS  no two cars closer than a car length (5.6 m) – closest 7.68 m (2.0 s, cars 55 / 66)
PASS  grid stands still before the lights – largest move 0.78 m over 50 s (noise bound 0.85 m)
PASS  seek back = fresh load (no state left over) – seek 95 s → 30 s
PASS  pit car on its pit lane while InPit (within 2 m) – 84 samples InPit, 0 off the lane
PASS  pit car stops at its box – 0 km/h for 3.00 s, place within 0.36 m
PASS  pit car leaves on a new stint (MEDIUM → HARD) – stints MEDIUM → HARD
demo: all checks passed
```

- **기준의 뜻:** 합성 위치에는 실제 피드처럼 x·y 각각 ±0.3 m의 잡음을 넣었으므로, 서 있는 차의 두 표본은 최대 0.85 m까지 다를 수 있습니다. "정지"는 이 범위 안인지, 피트 정차는 텔레메트리 속도 0으로 판단합니다.
- **범위와 한계:** 이 검사는 실행 경로와 기본 동작(유한한 값, 시간 이동, 출발 그리드, 피트 상태와 경로, 스틴트)을 확인할 뿐입니다. 실제 F1 위치 자료의 정확성, 47경기 스캔 결과, 3D 화면의 최종 자세를 대신하지 않습니다. 피트 경로 검사는 생성기가 정한 경로와 재생 결과를 비교하므로, 실제 서킷의 피트 레인 처리(`pitpath.js`)를 검증하지 않습니다.
